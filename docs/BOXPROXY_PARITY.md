# 辟尘代理：BoxProxy 对齐基线

> 基准来源：用户提供的 BoxProxy 26.09.12 APK 与《BoxProxy 不完全指南》。目标是复刻产品结构、交互和行为，不直接复制第三方私有源码/资源。

## 规则

1. 不再新增“只有 UI、没有后端”的按钮。
2. 页面显示为可用的能力，必须能落到真实 Root / 核心 / Clash API 路径。
3. 源配置、最终启动配置、运行模式、实际规则必须分离。
4. 当前模式不支持的能力必须置灰并说明原因，不假报成功。
5. 下一次测试包只有在首页、面板、工具、设置四层结构完整后才发布。

## 1. 首页 / 服务控制

- Root 状态
- 核心 / 模式 / 当前配置
- 启动 / 停止 / 重启
- 运行时长
- 上传 / 下载 / 活跃连接
- 节点选择快捷入口
- 面板快捷入口
- 日志快捷入口
- 后台运行不依赖 Activity
- 前台通知与快捷设置磁贴（后续阶段）

## 2. 面板 / Clash API

- 读取实际策略组
- 显示当前节点
- Selector 切换节点
- 单节点延迟测试
- 整组延迟测试
- 实时连接
- 规则 / 代理链 / 单连接流量
- 关闭单连接 / 全部连接
- 历史采集（后续阶段）

Clash API 仅监听 127.0.0.1，并使用随机 secret。

## 3. 设置 → 基础代理配置

UI 对齐用户提供截图：

- 核心选择
- 运行模式
- IPv6
- 自动覆写
- 查看启动配置
- 配置选择

核心：
- Mihomo
- Mihomo Smart
- Sing-Box
- Sing-Box reF1nd
- Xray
- V2Fly
- Hysteria

模式：
- TUN
- TPROXY
- eBPF
- Redirect
- Mixed
- Enhance

未接后端的核心/模式必须明确不可用。

## 4. 最终启动配置

- 源配置永不原地改写
- Mihomo / Sing-Box 使用独立 startup-config
- 根据运行模式隔离冲突入站
- 运行前由实际核心校验
- 支持重新生成与查看最终配置

## 5. 其他代理配置

按能力矩阵开放：

- TCP
- UDP
- DNS TCP
- DNS UDP
- DNS 劫持模式：关闭 / TPROXY / Redirect
- Mihomo DNS Forward
- QUIC
- IPv6 三模式
- 性能模式
- 厂商防火墙清理

## 6. 应用管理

- 黑名单
- 白名单
- 核心（全部交给核心）
- UID / GID
- 工作资料 / 分身 / 多用户

不同运行模式使用对应 iptables / TUN / eBPF 实现，不复用错误语义。

## 7. 工具

- 更新核心
- 应用管理
- 订阅管理
- 共享网络
- 绕过规则（接口 / IPv4 CIDR / IPv6 CIDR）
- 网络匹配
- CNIP
- 日志查看
- 文件管理
- Sub-Store 检测（后续）

## 8. Root 运行框架

目标替代目前过于简化的 proxy-root.sh：

- start / stop / restart / status / boot
- TUN / TPROXY / Redirect / Mixed / Enhance
- eBPF 只在兼容核心和实际能力满足时开放
- TCP / UDP 独立开关
- DNS TCP / UDP 独立规则
- QUIC 处理
- IPv4 / IPv6 独立能力探测
- 应用 UID/GID 规则
- 接口 / CIDR 绕过
- 共享网络
- 启动失败原子回滚
- PID 身份验证，避免误杀其他进程

## 9. UI

- 默认走 Miuix 风格，而不是临时测试工具风格
- 大标题 + 分组设置卡片
- 设置项采用“标题 / 当前值 / chevron”
- 选择项使用 Miuix 风格单选弹层
- 主页面只放服务状态与最常用快捷动作
- 高级配置进入设置/工具，不堆在首页
- 底部悬浮导航统一：首页 / 面板 / 工具 / 设置
- 不在首页直接输出整段核心日志；仅显示简短错误，完整内容进日志页
