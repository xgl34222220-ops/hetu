# 河图 test.5：状态显示与操作体验

基于 test.4 的 0c63498390631cd8e211e4b75472a44280264360。保留其 Root 超时修复、CNAME、档位、网络恢复、原 APK 图标。preview 包名不变；版本码 305；交付时使用保留的 test.2/test.4 私有签名。

## 已实现的源码变更

1. 区分状态读取失败、未安装、等待重启、待卸载、管理器停用、已暂停、挂载未确认、保护已开启及 VPN 启动/恢复。错误返回不能凭部分 enabled/mounted 字段显示模块保护开启。
2. 用户在 Root 管理器停用/卸载模块后，不擅自重新启用。启用与重新应用前读实际状态；停止 VPN 时取消已被用户停用决定取代的旧恢复意图。待重启时暂缓恢复。
3. 从后台回来，对此前已确认 Root 授权的状态重新检查。拒绝授权时不自动反复请求。
4. 规则同步先读取小体积配置；不可变 generation/revision 未变化时，跳过完整域名列表导出，减少一次 su 调用及列表解析；有变化仍校验两份快照版本一致。不是省略状态检查，没有宣称真机速度已达特定值。
5. 底栏文字与图标居中；高度随字体放大增加。统计变化只更新已有数字控件，不重建首页。网络/模式改变仍更新页面。
6. 新 VPN 操作取代旧页面轮询；系统拒绝启动时清除该次启动意图。完整错误返回在“查看诊断详情”中查看。

## 验证边界

本地新增 19 个状态断言与 4096 种标志组合检查通过；既有协议、模块及真实进程（假 su 环境）回归通过。CI 将安装本次 APK，在 1.3 倍系统字体下检查四个页面、导航中心线、图标及模块导出，并以明确标注的模拟状态验证错误/暂停/禁用/卸载/待重启显示。以最终 CI 和交付校验记录为准。

模拟状态不是 Root 框架，Android 模拟器不是用户 ReSukiSU 或 OEM 手机。本轮没有实际广告效果、登录支付或用户设备重启验收。模块 ZIP 不变，已安装 0.3.0-beta.1 无需重刷。不修改 main，不发布正式版。
