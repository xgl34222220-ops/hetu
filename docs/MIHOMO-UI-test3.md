# 辟尘 0.4.0-test.3：代理工作台与已观察连接

在已交付 test.2 / code402 / 7e6e3c82223875dc79023fb512ec8ebd82995ef7 基础上改进，不向用户回退发送 test.1。

## 实现

- 原生代理工作台拆为概览、节点、连接、设置。统一四页浅/深色、分层圆角、悬浮底栏；使用系统安全区避开状态栏、挖孔和键盘。保留用户原始图标，没有新画图标或内嵌字体。
- 概览给出真实服务状态、原配置类型、内核流量累计及活跃连接数。没有把流量数当广告次数，没有虚构测速或流量曲线。
- 节点组自动加载，支持按组名/成员搜索；选择弹窗显示内核当前勾选，切换成功后重新读取确认。自动测速/故障切换组显示实际类型，不伪装手动选择。
- 当前连接支持域名/地址/规则/出口搜索、详情和暂停列表刷新。复用 ListView 和行，刷新不重新建整个页面或销毁输入框；暂停列表刷新不会停止 VPN 或服务端采样。
- 新增可选的本机“最近观察”。默认关闭，连接期间每2秒观察内核活跃快照，最多300条按连接ID去重更新。记录放在App私有目录，约10秒合批写入和停止时写入，停止代理后可回看。关闭开关保留旧记录；清空/关闭使在途旧样本失效。损坏/存储失败显示提示。只保存选定连接元数据，不保存配置、订阅令牌、请求正文，也不猜测应用UID。
- 配置仍使用test.2的单文件原子事务和回退；新增不含订阅地址的本机摘要。

## 不混淆的边界

“最近观察”是活跃连接采样，可能遗漏2秒以内的短连接，不是所有访问历史，也不是DNS/REJECT事件日志。异常进程退出可能丢失尚未写盘的最近一批（约10秒）。采样连接不等于广告拦截。关闭开关不会删除以前记录，删除需清空。没有跨应用归属采集。

未更换Mihomo内核、Root模块或图标。现有Root TPROXY/eBPF、完整事件日志、内容去广告、所有协议兼容性、物理切网/休眠、DNS/WebRTC泄漏、异常退出阻断及实际Root恢复的未验收范围仍然存在。本次不是宣称全部长期计划完成。
