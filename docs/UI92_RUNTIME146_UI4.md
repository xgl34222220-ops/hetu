# 河图 UI4：完整视觉稿原生化

基础为已发布UI3，功能继续使用原146。用户的新Vue稿只作为视觉与交互依据。
保留河图名称、实际服务状态、真实数据、配置和已有功能入口，不引入模板中的定时模拟启停、硬编码IP或空按钮。

## 本轮改动
- 标题居中22sp，保留独立刷新和更多菜单；浅色窗口及页面底色统一为#EFF2F8。
- 状态标题22sp，运行时间15sp，核心13sp、配置15sp；正常字号使用80dp加粗矢量徽标，大字体缩小装饰而不缩小正文。
- 运行/处理/停止三态及真实回调保留，启动胶囊显示“启动服务”，处理中的旧按钮仍不能误触。
- 无边框22dp卡片、双层轻阴影、16sp快捷入口、12dp网格间距；订阅与CPU条仍由实际数据驱动。
- WAN/LAN移除Crossfade，任何时刻只组合一份地址内容；整卡点击、详情隔离、横滑和纵向滚动保留。
- 地址独占完整内容宽度，IP标签置于上方；IPv4/IPv6按可用宽度换行，不使用省略号、不缩小系统字体。此处为完整显示而调整模板的同行排版。
- 延迟超时/失败用小徽章展示，适用于所有自定义测速目标，正常数值和单位继续分级。
- 悬浮底栏保留真实毛玻璃和页面切换，64dp高度，只有选中项显示文字，所有图标保留无障碍名称和独立触摸目标。
- 底栏外壳改用标准原生圆角裁切，不依赖圆角RuntimeShader；启用时的Haze/折射效果保留。
- 网络详情保留可拖动原生抽屉，32dp顶部圆角、居中标题和确认按钮；未知ISP/ASN仍为未提供。
