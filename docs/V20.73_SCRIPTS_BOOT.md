## 开机自启

原开关仅保存 proxyRootAutoStart，没有安装界面所称 Root 开机脚本；原恢复在 Root/网络延迟时会停止重试。

新开关在后台安装并检查 `/data/adb/service.d/hetu-autostart.sh`、Root 私有启动计划及最后成功部署的配置。安装/移除失败保留原设置并展示错误。失败信息在 Compose 状态读取阶段取得，让列表构建器随错误变化刷新；留在本页时也能显示和清除提示。启用前需已成功启动所选核心，并重新校验实际已部署配置，网络设置变化需先启动/重启应用。已有旧开关设置在下一次成功启动时迁移。

脚本自行启动保存的 native 代理，等待系统完成和实际路由出现；不依赖用户打开 APK。复用完整启动参数，但重新验证配置和内核能力。应用恢复等待 native 事务；手动启动先完成时不会再次重启。停止在当前 boot-id 下取消恢复，下一次开机可按已启用的开关启动。Root 配置和启动计划仅 Root 可读。

应用在解锁后只接纳本次开机已确认运行的 native 代理；继续保留未安装 native 脚本时原有 wanted/授权恢复语义。诊断包含 Root 开机状态和有界恢复日志。
