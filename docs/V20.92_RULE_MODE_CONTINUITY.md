# V20.92：工具规则模式的请求归属与测速失效

## 问题与改动

工具页的“切换规则模式”原先直接使用动态控制客户端，PATCH 与确认 GET 可以在设置变化时读取不同端点，且成功写入没有通知其他页面废弃旧测速。现在工具入口委托 `ProxyDashboardRepository`，在派发前捕获同一端点、凭据与运行状态。成功 PATCH 立即推进共享观察代际；后续确认失败也不能让旧网站测速继续生效。迟到请求若已不属于当前控制接口，应返回接口变化提示。

本批生产范围仅为 `ProxyDashboardRepository.kt`、`ToolsRuntimeBridge.kt` 和版本字段（2092 / `0.12.19-v20-glass`）。不修改 TPROXY/TUN 偏好、Root/autostart 脚本、权限、依赖、主题 ABI 或既有首页/panel/工具布局；保留 V20.91 设置玻璃组件。

## 可运行对照与回归

新增 `RuleModeMutation92Test` 的五个方法均从原工具入口调用，HTTP 夹具核对路径、方法、Bearer 与 PATCH 请求体。覆盖拒绝写入保留旧测速、成功写入先于迟到确认使旧测速失效、确认 401/500、控制接口替换期间的迟到 PATCH 与迟到 GET。新旧对照仅将两份生产文件还原到准确前驱 `d7295d1aec1ffb17a0076d4dc9a8a4122d467447`；测试不调用仅新源码存在的方法。

保留前驱 639 项 / 66 个 XML 的完整测试身份和源码字节，新增后为 644 项 / 67 个 XML；独立 36 项、原 API35/36 的 65 项、安全门禁、900 秒 host 模型与 API36 原生内核受控测试的原预算和断言继续执行。历史 V20.91 失败对照在精确的临时 V20.91 源码视图中执行并单独标记，不能充作本批生产代码的验收。
