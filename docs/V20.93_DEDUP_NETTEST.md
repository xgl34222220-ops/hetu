### 受冻结基线测试约束、仍保留源码（无应用内入口或为同一功能的两处查看）
- `DiagnosticsScreen`、`ConfigsScreen`、`AdblockScreen`、`HomePublicIpScreen`、`HomeResourcesScreen` 等 Composable：V20.93 门禁要求 644 项基线测试源码逐字不变，其中有测试直接渲染这些函数，所以源码保留；它们已没有应用内入口（旧 `app/HomeScreen.kt` 本身未被调用）。
- 「查看启动配置」：设置›基础代理配置（`StartupConfigViewerFeedbackTest` 点击该行）与工具›诊断工具「启动配置」（`ToolsDiagIntakeTest` 点击该行）各被一项冻结测试锁定，两者使用同一个 `StartupConfigViewer`。本批不能删除其中一处，保留并在报告中说明。
- 首页「延迟」卡片（自定义目标的常驻概览）与「网络测试」：前者是首页状态卡，后者是完整测试页，功能不同，保留。

## 3. 网络测试页
- 大标题「网络测试」、右上刷新；分段「连通性 | 网速」。
- 连通性：AI 服务（ChatGPT、Claude、Doubao、Gemini、Grok）、社交媒体（Discord、Douyin、Reddit、TikTok、X、Telegram）、影音娱乐（Apple TV+、Bilibili、Disney+、Hulu、Netflix、Spotify、Twitch、YouTube）、工具与服务（Alibaba、Apple、Cloudflare、GitHub、NetEase、PayPal、Steam、Tencent、Wikipedia、Google、Baidu）。成人站点不收录。
  - 品牌图标：Simple Icons 16.34.0（CC0）路径数据，打包为 Compose `ImageVector`（`NetBrandIcons.kt`），按品牌色着色；Simple Icons 没有的（ChatGPT、Doubao、Grok、Disney+、Hulu、NetEase、Tencent）用品牌色字母方块。运行时不下载任何图标。（V20.93 门禁只允许改 Kotlin 包内源码，所以没有新增 res/drawable。）
  - 右侧：上行出口地区（国旗 + 代码），下行延迟 `387ms`；测试前「—」、进行中「测试中」、被拒为红字「未解锁」，失败显示原因（超时/解析失败/TLS 失败…）。
  - 全部服务在 IO 并发（同时 14 个请求），每完成一行立即刷新该行（每行独立状态，不重组整页）。
  - 地区只来自实测：① 该服务自身主机的 Cloudflare `/cdn-cgi/trace` 的 `loc`（必须同时有 colo/fl 行）；② 否则读一次 core.log 中该主机的策略链，若出口叶节点与某个已 trace 的服务相同，沿用其 `loc`；③ 策略为 DIRECT（或代理未运行）时，用不经代理的 Cloudflare trace 得到本机出口；其余不显示。
  - 未解锁：服务返回 403/451；或 AI 服务（ChatGPT/Claude/Gemini）实测出口在其不服务地区（CN、HK、MO、RU、BY、IR、KP、SY、CU）。
- 网速：经当前节点连接 speed.cloudflare.com：`/meta` 得出口地区与 IP（含 ASN 组织），`__down?bytes=0` 测延迟（去掉首个握手样本取中位数），3 路并发下载 8 秒、上传 8 秒；大号 Mbps 读数、「开始测速/停止测速」、测速结果（延迟 ms、下载 Mbps + 字节、上传 Mbps + 字节）、实时速率曲线（只在绘制阶段读取样本）。全部在 IO；离开页面或应用进入后台立即取消，并通过监视协程关闭套接字，阻塞中的读写马上返回。
