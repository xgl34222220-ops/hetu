# V20.64 tools root geometry measurement

The Tools root reference screenshot was measured against the current controlled capture at the same 393px viewport width.

- Two-row reference card: about 147px; current capture: about 132px.
- Single-row reference card: about 74px; current capture: about 68px.
- Three-row reference card: about 221px; current capture: about 196px.
- The production row primitive currently uses a 64dp minimum height. A 72dp minimum height brings grouped card heights to the measured reference geometry without changing labels, routing, or functionality.

This is an internal parity note. It is not a declaration of full 173-state acceptance.
