# 0.3.0-beta.1 验证记录

执行日期：2026-09-13（UTC）。构建、纯协议测试与 Linux 隔离回归不能替代实际手机验证。

## 自动化验证范围

- 模块 17 项隔离回归：旧 schema 迁移、第四来源默认关闭及回滚、完整配置原子导入、下载失败保留、白名单优先、挂载失败恢复、暂停/开机/回滚、恶意输入、清单损坏、外部挂载、卸载恢复和安装预检。
- DNS 协议 97 项断言及 100000 个畸形输入；缓存 30 项断言及 25000 个畸形响应；DoH 传输 22 项断言，覆盖响应校验、HTTP 错误、退避和模拟连接取消。协议测试不依赖真实公网服务。
- 规则解析 63 项检查，包含四个规则快照、大于 8 MiB 的合并规则、单源与整批限制、中断和下载总时限。
- App 以 API 35 编译（minSdk 26 / targetSdk 35），打包检查 APK v2/v3 签名、ZIP 对齐、模块根入口及内置/独立模块逐字节一致性。
- `tools/verify_downloads.py` 核验仓库里实际交付的 APK 签名、版本、SHA-256 和模块与当前源码构建一致。

最终执行结果以根目录 `BUILD_REPORT.txt` 和当前提交的 GitHub Actions 状态为准。上述测试代码随仓库提供，不以文件存在冒充执行成功。

## Android 仿真尝试

使用 Google 官方 Android 35 x86_64 镜像、Emulator 与 platform-tools，纯软件 CPU（无 KVM）尝试启动。ADB 可连接，但限时内系统 package/Activity 服务未就绪，`pm list packages` 返回 `Can't find service: package`，系统截图全黑。因此没有取得 App 安装、启动、界面截图或 VPN 运行的验证结果。这是验证环境限制，不能据此认定 App 已通过或已失败。
