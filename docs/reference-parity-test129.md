## 实现与验证边界

- 版本 `0.4.0-test.129-preview`，versionCode `529`。
- 新增行为测试覆盖策略过滤/排序/展开、API 模式写入、IPv6 无回退、多用户 UID、SQLite 去重/保留、文件名/编码、YAML 注释/锚点/非 BMP 字符保留、严格 JSON 与官方 Schema、面板地址及 ZIP 路径校验。
- 新增实际 Compose 测试覆盖底栏双向拖动且每次仅一次切页、编辑器未保存返回、主题切换和窄屏表单。已有渲染测试固定中文参考环境。截图来自实际组件与测试数据，不是真机录屏。
- MIUIX 0.9.3 的 JVM 类使用 Java 21，因此构建与测试运行环境升级到 JDK 21，Android 源码目标仍为 Java 17。
- 受保护运行文件仅修改 `MihomoControllerClient.java`（读写模式、IPv6 探测）和 `RootProxyPolicy.java`（跨用户 UID 解析），相应摘要基线有意更新。其余 32 个保护文件、Root 网络脚本和原生核心未修改。
- 本地容器不提供真实 Root/Android 内核能力。既有进程可执行文件 `/proc` 身份测试在此环境失败；完整网络与进程身份回归仍由 Linux CI 执行，未跳过或放宽这些门禁。
- 真机 Root 文件操作、多用户工作资料、OEM 键盘/预测返回、持续帧率、硬件折射及节点 IPv6 实际连通性仍需要设备验收。
