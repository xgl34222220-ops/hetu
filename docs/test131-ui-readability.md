# test.131：按附件落实 Android 界面优化

本次修改实际 Compose 页面及共享组件，依据用户附件中的裁字、拥挤和信息层级问题。版本为 `0.4.0-test.131-preview`，versionCode 531，沿用固定预览签名。

## 页面变化

- 首页：运行状态分层排版，启停和重载/停止/重启操作保持独立；延迟卡片在窄屏、大字号下转为纵向；WAN、网速、订阅和资源卡片随内容增高，数值不会被固定行高截断。底栏随字体增高，列表末项预留真实底栏高度。
- 策略：策略组名、当前节点和协议/延迟分层；默认完整换行，旧“裁切”偏好按换行处理，显式滚动偏好保留。节点列数受宽度与字号约束，手动指定列数成为上限。选中标记使用真实测量的节点位置和尺寸，适应每行不同高度；增加明确选中勾选。测速点击区域与选节点区域分开。
- 延迟：取消文字切换时可能裁字的尺寸动画，统一数字行高与字体留白；高延迟与中延迟使用可读的警告色背景，失败使用错误色。测试同时检查文字边界和实际渲染背景的对比度。
- 面板：订阅名称、剩余比例、上传/下载/剩余用量分层，进度条、到期和更新时间完整显示；排行榜数字、流量和长域名重新排版，维度按钮自动换行，长名称可点开。
- 日志：JSON/logfmt 日志展示时间、级别和正文，保留原始记录展开与复制；无法解析的记录按原文展示。搜索、级别、刷新和清理入口保留。
- 工具和设置：14 个工具入口按核心网络、规则与订阅、运行维护分组，原回调全部保留；共享设置说明完整换行。文件空状态提供新建/导入、清除搜索或重试的实际入口。
- 全局：统一字体留白、行高和柔和卡片材质，减少厚边框；保留玻璃底栏和按压反馈。内容布局不依赖强行缩小字体。

## 自动化验证范围

- 生产首页与真实底栏：320/360/412dp、1.0/1.5/2.0 字号、明暗主题；检查延迟和快捷卡文本布局、操作触发次数及末项可滚到底栏上方。
- 策略及节点：同一宽度、字号、主题矩阵；覆盖长中英文节点名、99999ms 延迟、旧裁切偏好、强制三列、独立测速回调及选中背景实际边界。
- 订阅、排行榜和结构化日志：320dp、三档字号、明暗主题；检查比例、数字、正文边界、刷新事件隔离及原始日志保真。
- 原有渲染、功能和网络回归继续作为构建门槛。`tests/ui-runtime-baseline.json` 与受保护的运行配置、Root 脚本和连接处理文件保持 test.130 原值。

## 验证边界

Robolectric 原生 Skia 截图使用系统字体；首页截图关闭 GPU 玻璃和 squircle shader，使用库提供的形状回退绘制，保留生产底栏布局和事件。它们不能替代用户设备上的 OEM 字体、GPU 玻璃合成、锁屏或微信收信验证。本次不宣称微信漏消息已解决；test.130 的按策略组清理旧连接修复继续保留。
