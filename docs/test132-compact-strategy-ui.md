# test.132 · 紧凑首页与策略面板

用户确认轻玻璃视觉方案，并要求策略面板参考 zashboard。本次修改实际 Android Compose 页面，版本为 0.4.0-test.132 / versionCode 532。

## 页面与交互

- 首页：左对齐标题，运行状态及三个操作共用主卡；快捷入口增加图标；延迟三列突出读数；WAN/网速/订阅/资源共用四格面板，WAN 详情入口可直接打开详情。
- 策略：默认字号的 320dp 页面可显示双列，标题工具栏收紧，组卡片名称和当前节点最多两行，展开入口保留完整语义。
- 节点：默认独立底部面板，保留显式页内展开偏好。支持组内搜索、配置/名称/延迟排序、升降序、测速通过筛选、列表/双列、名称长按展开、子策略进入和返回。继承已有排序、订阅分组及列数偏好。
- 节点列表按需组合。选择、单节点测速、进入子策略为独立操作。接口失败显示原因且不改变当前选中节点；确认成功后更新选中状态。已有按策略组清理连接逻辑不变。
- 批量测速最多并行 6 个，去重并传播取消，结束清理排队/运行标记。失败覆盖旧值；延迟升降序始终将未测和失败放在后面。
- 减弱底栏选中填充，节点选中颜色过渡为 220ms；保留动效开关、GPU 玻璃路径及软件回退。

## 参考

zashboard 官方移动端：<https://github.com/Zephyruso/zashboard>，MIT，参考提交 `b83a63aeba1a08be62ee4d6228874e1229a12d1b`。阅读了 ProxyGroupForMobile、ProxyGroupHeaderForMobile、ProxyGroupPanel、ProxyNodeCard 和节点筛选排序相关实现，以原生 Compose 重写交互，没有复制 Vue 源码。

## 验证范围

69 项 Android 测试覆盖既有回归及新增筛选排序、并发取消、真实组件、真实策略页控制器失败/成功交互。原生 Skia 渲染覆盖 320/360/412dp、1/1.5/2 倍字号及明暗主题，检查文字边界、独立测速点击、长按完整名称、列表按需组合和底栏避让。首页渲染高度为 800dp。

受保护的网络运行文件按原基线逐文件核验，不修改基线。测试截图使用样例运行数据，GPU 玻璃/squircle 使用回退绘制；不替代 OEM 自定义字体和 GPU 实机验证，不宣称微信漏消息已解决。
