# test.89：网络策略生效、运行稳定性和界面

## 修复

- 禁用本机 IPv6 同时处理运行 YAML、DNS AAAA 响应、系统接口设置和 IPv6 外连防火墙。换网后重新校正被系统恢复的接口设置；停止时恢复原状态，失败保留恢复记录。
- IPv6 状态检查读取实际接口值及防火墙规则，不再将备份文件存在视作禁用成功。设置页区分选中设置与实际运行设置，并提供明确的应用并重启入口。
- 修复换网回调乱序导致旧连接清理被取消、网络事件风暴重复调度，以及自动启停与手动操作之间的竞争。
- 广告计数按运行代次提交，处理日志跨块断行，避免旧轮询覆盖新会话。UI 可复制日志先脱敏再裁剪。
- 公网信息改为单个后台请求，失败退避；真实网络或已应用设置变化后丢弃旧缓存，避免查询阻塞面板刷新。
- 修复 AdGuard 条件规则被扩大为整域拦截、失效下载路径和首次离线规则缺失；保留手动黑白名单优先级。详见 [规则修复说明](adblock-test89.md)。

## 界面

- 首页突出运行状态和启动进度，提供连接、过滤和诊断入口；窄屏或大字体采用两行操作按钮。
- 连接页面支持应用、域名和规则搜索，以及分批查看更多；批量断开需要确认。
- 保留页面滚动位置，改善长设置值、文字缩放、暗色图标和触控区域，去掉持续运行的装饰动画。
- 移除没有实际生成分支的“自动覆写”开关，明确说明运行副本保留原始订阅。

## 验证与边界

本地主机测试覆盖连接连续性、启动探针、日志脱敏、调度、运行设置签名、IPv6 YAML、异步缓存、规则解析及并发快照；Root shell IPv6 70 项、控制接口 50 项检查通过。Android 编译与原生核心测试由构建工作流执行。

本次没有取得用户设备日志，也未完成真机界面与微信收信时延测量。模拟器未成功启动至可安装应用的状态，不能把静态布局检查当成截图验收。源码修复不能代表所有机型已经验证。

禁用本机 IPv6 不控制代理服务器的公网出口地址。检测网站若通过代理节点访问，显示节点 IPv6 不能单独证明本机发生 IPv6 泄漏；应结合应用内实际生效状态及直连流量检查。

覆盖安装后，请主动重启一次代理，替换正在运行的旧版 Root 脚本并应用设置。原始订阅、DNS/WebRTC 规则以及用户选择的 eBPF/TPROXY 模式保留。
